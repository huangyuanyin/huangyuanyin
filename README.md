#### 🌐 Wegic 1.0

- **项目介绍：** 对话式 AI 建站平台，通过自然语言完成网站设计、内容编辑与发布。
- **核心架构：** DSL 驱动的组件渲染，将建站需求转为结构化页面描述，由组件渲染引擎生成网站。
- **体验地址：** [wegic.ai](https://wegic.ai)

#### 🎨 即时设计编辑器

- **项目介绍：** 类 Figma 的在线协作 UI 设计工具，覆盖原型设计、UI 设计、交互动效与开发交付。
- **核心架构：** React 交互层 + 文档与图层数据模型 + CanvasKit 画布渲染，结合视口与坐标变换、命令与撤销重做、WebSocket 实时协同及 IndexedDB 本地持久化。
- **体验地址：** [js.design](https://js.design)

#### 📚 信安知识库

- **核心架构：** Next.js / React 应用层 + Tiptap 富文本编辑与实时协同 + Django 服务 + Prisma / MySQL 数据存储。
